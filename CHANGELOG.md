# Changelog

The milestones of InstaStylr, newest first, from the commit history.

## October 2026

- **2026-10-10**: README, architecture overview, screenshots and this changelog.

## June 2026

- **2026-06-19**: Divider blocks: a builder with line, framed, bookend and pattern recipes, wrappers and 209 presets. A richer bullet picker with 290 markers in 14 categories.
- **2026-06-14**: A More menu for lists and dividers, a choice of platform for the character limit (Instagram, YouTube, TikTok, X, Threads, Facebook, LinkedIn), and a custom bullet per list.
- **2026-06-14**: Strict Content-Security-Policy and security headers in nginx.
- **2026-06-14**: Document state machine: a title with an unsaved-changes dot, a Save button that becomes Save, Update or Saved, and a confirmation before discarding work. Settings and a side menu. The browser tests were rewritten against the new interface.
- **2026-06-12**: Interface redesign: header actions, saved posts, light and dark themes.
- **2026-06-12**: Browser tests (Playwright) and static deploy tooling.
- **2026-06-12**: First commit. A rebuild as a fully client-side static app: eight fonts as data, bold and italic, lists emitted as plain Unicode, an emoji picker, a grapheme-based character counter, autosave and a starter caption template. 68 tests.
